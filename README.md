# OBScore

![Screenshot of OBScore](https://i.imgur.com/ba5i6ih.png)

OBScore is a scoreboard system for controlling and displaying player tags / names, scores, characters, round and much more.
The controller component of OBScore is designed to be used as an [OBS browser dock](https://youtu.be/E0LLb6SfqRc) but can also be run from a normal browser.
